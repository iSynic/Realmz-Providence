# Author Player Maps and notes

Open **Player Maps** to manage the Maps and Notes records shown to the player.
These records describe their own presentation; they do not replace Land or
Dungeon level authoring.

Select a record with **Search name, ID, note, target…**, or choose **New Player
Map** in an editable project. Edit the available/unavailable names, note, target
map, display rectangle and presentation settings. Use **Choose target map…**,
**Choose picture…** and **Choose TEXT…** to select actual referenced content.

The draft preview shows the presentation being edited. Use its zoom and Refresh
controls to inspect it. **Open Map**, **Open TEXT** and **Open picture preview**
lead to the selected owning content; review any draft guard before leaving.

## Place markers

The marker area exposes all ten slots. Select a slot and **Choose icon…**, then
set X/Y or use **Paint selected marker**. Click or drag to move that marker;
Escape stops painting. **Clear slot** removes that slot's marker deliberately.
Inspect the preview after changing a target, rectangle, scale or marker.

Choose **Apply Player Map** to commit the draft, then Save. **Discard** restores
the applied record. Callers show known references to the selected record. A
missing resource must be resolved explicitly; a generic replacement icon is not
an exact substitute for the scenario's selected resource.

If the result is unconfirmed, use **Resolve outcome** and keep **Copy draft** for
reference. Do not retry the mutation blindly. In-game display and current-party
marker behavior require a separate runtime check.
