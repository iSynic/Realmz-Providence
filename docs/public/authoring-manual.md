# Providence authoring manual

These chapters describe the current native development editor. The published
beta's contract and remaining limitations are recorded in the
[release notes](beta-release.md). Apply changes the open project; Save persists
it. A preview, successful export or screenshot does not certify a whole campaign.

| Chapter | Authoring task |
|---|---|
| [Getting Started](getting-started.md) | Make and verify a small playable change |
| [Scenario Setup](scenario-setup.md) | Create, open, import, save and recover a project |
| [Scenario Shell](scenario-shell.md) | Set the start, restrictions, contact information and hooks |
| [Land/Dungeon Maps](maps.md) | Paint terrain, place events and connect locations |
| [Player Maps](player-maps.md) | Author the maps and notes shown to players |
| [Action Points](action-points.md) | Author ordered actions, activation and applied context |
| [Strings & Text](text-and-messages.md) | Write messages and follow their callers |
| [Encounters](encounters.md) | Author responses, conditions, Rogue outcomes and schedules |
| [Combat](combat.md) | Author monsters, variants and battle placements |
| [Economy](economy.md) | Author items, treasure and shops |
| [Characters & Magic](characters-and-magic.md) | Author spells, races and castes |
| [Assets](assets.md) | Select, import, preview and deliberately apply media |
| [Validate & Publish](validate-and-publish.md) | Resolve findings and export a selected target |

The [Random Message repair guide](random-message-repair.md) follows one guided
repair in detail. [View Flow](view-flow.md) explains its derived relationships.
Use the [compatibility glossary](compatibility-glossary.md),
[supported formats](supported-formats.md) and [source evidence guide](source-evidence-guide.md)
when a warning or compatibility boundary needs explanation. These files are
usable now; the integrated native Documents viewer is still under development.
